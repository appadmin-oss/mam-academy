Turn 5 · Admin console

Desktop-first, built on the v2 schema

A replacement for the 8,600-line, 37-view admin. Desktop-first because this is where an administrator sits for two hours at a time with two monitors, and the mobile build is a deliberately narrow subset — the four decisions worth making from a phone, not the whole console squeezed.

One enrolment model

v2 has a single enrolments table, so the console no longer needs the dual-read language v1 grew. One roster, one status vocabulary, one place a student can be.

One intake table

Programme, summer, scholarship and audition are a type on one row, so admissions is finally one funnel view with one set of statuses — and a rejection cannot save without a reason.

Money that reconciles

Minor units with a frozen FX rate per row and a balanced double-entry ledger, so "why does this family owe ₦8,000" is answerable by reading, not archaeology.

Permissions as rows

Roles attach to a membership and can be narrowed to a centre, so "administrator, Lagos only" is expressible — and the break-glass credential has an identity in the log.

Displayed currency is not charged currency

Accounting stays in USD. A guardian in Lagos reads naira, one in London reads sterling, and the total is computed from the USD source rather than summed from rounded lines.

Summing rounded conversions per line is where the one-cent mismatch comes from, and a family reads that as a pricing error.
Curriculum year does not pin fees

A student keeps the requirements they enrolled under, but pays the current published schedule. Two different guarantees, deliberately — conflating them would freeze an academy's prices for four years.

Charges & exceptions

Punctuality is recorded for everyone · charging is off for both parties

Instructor deductions · disabled

Deducting a fine from pay needs an authorised labour officer's written consent under the Labour Act. The academy holds none, so this switch is off and locked. Lateness is recorded and goes to appraisal instead.

Student charges · off

A fine on a child for a guardian's traffic converts a shared obligation into a price, and the evidence is that lateness goes up. Lateness still records at zero so the pattern stays visible.
